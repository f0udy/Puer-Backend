## ✨ Overview

**Puer** is an open-source Android music player focused on fluid 60/120 FPS animations, ultra-fast response times, and minimal battery consumption. Built with modern Android development standards, it combines clean UI design with a robust audio engine.

---

## 🚀 Key Features

* ⚡ **High Performance:** Built using Jetpack Compose with optimized rendering pipeline for smooth transitions and low CPU usage.
* 🎵 **Smart Audio Engine:** Powered by AndroidX Media3 (ExoPlayer) featuring intelligent audio stream caching.
* 🎨 **Minimalistic UI:** Modern interface with dynamic themes, smooth gestures, and a clutter-free layout.
* 📜 **Synchronized Lyrics:** Real-time syllable/line synced lyrics support via open APIs.
* 🔋 **Battery Efficient:** Optimized background service execution to minimize power consumption.
* 🔓 **100% Open Source:** Free of ads, proprietary telemetry, and hidden trackers.

---

## 🛠️ Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose, Material 3 Design
* **Architecture:** MVVM / MVI pattern, Kotlin Coroutines & Flow
* **Audio Engine:** AndroidX Media3 (ExoPlayer)
* **Image Loading:** Coil
* **Networking:** Ktor Client / Retrofit
